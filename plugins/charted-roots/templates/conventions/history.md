# History

`History/` holds maintenance write-ups, not entity data. Each task is a pair: reusable method `<task>.md` + run record `<task> - Report.md`. Together they document the verification suite — read them before bulk work and re-run the relevant pass after a re-import.

- Baselines, run dates, counts and per-item findings go in the run record.
- `History/` quotes wikilinks to deleted notes on purpose; mask code before link audits.
