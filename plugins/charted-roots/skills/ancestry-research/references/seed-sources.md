# Starter source catalogue

The catalogue is maintained by the upstream skill's author and project contributors. Choose routes from it by question, place and period; going through every site before drawing a conclusion is not required. Check the record's provenance, the owner and the access conditions when working with the chosen source, filling in missing details as the research proceeds. Check dates apply only to the resources explicitly listed, not to the whole table. Any use of these online resources needs the user's authorisation for web work on the task (SKILL.md, Rules that win).

## Classes

- **A — institutional/official**: preferred for catalogues, scans and stable identifiers.
- **B — reputable index/thematic project**: useful, but the entry must be linked to the original.
- **C — community/lead**: use for local hints; does not confirm kinship.
- **Q — quarantine**: do not use as evidence; unclear provenance, personal data, access restrictions or instability are possible.

## Rule for adding new sources

When adding a useful source, give the known details and mark the missing ones as unknown:

`owner; country/jurisdiction; collection type; originals or index; stable ID; access; restrictions; typical errors; date of last check.`

New rows go into this vault copy by hand; do not re-sync this file from upstream (SKILL.md).
